# TechDrive OS

**A retro-inspired 32-bit operating system with a classic Windows XP-inspired experience.**

TechDrive OS is an experimental operating system project focused on bringing classic desktop computing aesthetics together with native utilities, command-line tools, and filesystem experiments.

## 🚧 Project Status

TechDrive OS is under active development. Features, hardware compatibility, filesystem behavior, and stability may vary between releases.

This project is provided **free of charge**. The official release is distributed as a bootable ISO image.

## ⚠️ Important Warning — Read Before Use

**TechDrive OS is experimental software. Use it at your own risk. It is strongly recommended to test this software on a virtual machine rather than real hardware.**

* **Always test on a virtual machine first.** Run the ISO inside VirtualBox, VMware, or another suitable virtual machine environment to prevent unintended hardware behavior.
* **Protect your data.** Do not use TechDrive OS with important files or your primary storage devices.
* **Storage operations may be unsafe.** Filesystem and disk-writing features are experimental. Bugs could cause data loss or filesystem corruption.
* **Hardware compatibility is not guaranteed.** TechDrive OS may fail to boot or may not work correctly on some computers.
* **Crashes and incomplete features are possible.** Some functions may be limited, unfinished, or unsupported.
* **Back up important data.** Keep independent backups before experimenting with operating systems or disk tools.
* **Do not assume security or reliability.** TechDrive OS has not undergone a comprehensive security audit or real-hardware compatibility test.
* **Do not use it for critical workloads.** It is not intended for production systems, business-critical data, or systems that require guaranteed reliability.

The developer makes no guarantee that every feature will work correctly or that the operating system will be compatible with your hardware.

## 🖥️ Project Goals

TechDrive OS aims to develop a lightweight, retro-inspired computing environment with:

* A freestanding 32-bit x86 kernel.
* GRUB Multiboot-compatible booting.
* A command-line shell and system utilities.
* A classic Windows XP-inspired desktop experience.
* Native applications and diagnostic tools.
* Memory, hardware, and system-information experiments.
* Filesystem support and storage-management experiments.
* Automated build checks and regression tests.

**These are project goals and areas of development, not a guarantee that every feature is complete in every release.** Consult the release notes for the status of a specific version.

## 🚀 Getting Started

1. Download the ISO from the official Releases page.
2. Read the release notes and any included instructions.
3. Create a new virtual machine configured for a compatible 32-bit x86 environment.
4. Attach the ISO as virtual optical media.
5. Boot the virtual machine and follow the on-screen instructions.
6. Avoid attaching real disks containing important data while testing experimental storage features.

Virtual machine settings and compatibility may differ depending on your virtualization software.

When reporting a problem, include:
